# Payment Data Analysis

## Описание проекта

Данный проект посвящён анализу и прогнозированию данных о платежах за медицинские услуги. В рамках работы проводится исследование трендов, типов услуг, демографии пациентов и построение моделей для прогнозирования будущих платежей. Анализ выполняется на полном, нефильтрованном датасете без удаления выбросов и дубликатов.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL-репозитория>
   cd <имя-папки>
   ```
2. Установите зависимости:
   ```bash
   pip install -r eda_prophet_sarima/requirements.txt
   ```

## Основные функции

- Загрузка и минимальная предобработка данных
- Анализ временных рядов платежей (месячные/годовые тренды, темпы роста)
- Анализ типов услуг (топ-услуги, динамика, средний чек)
- Анализ поведения и сегментации пациентов
- Прогнозирование платежей с помощью моделей SARIMA и Prophet
- Визуализация результатов анализа и прогнозов

## Используемые технологии

- Python 3.8+
- numpy, pandas
- matplotlib, seaborn
- statsmodels, scipy
- Prophet


## Архитектура проекта

- **data/** — исходные и обработанные данные
- **eda_scripts/** — скрипты для анализа (предобработка, анализ трендов, услуг, пациентов, прогнозирование)
- **eda_results/** — результаты анализа и визуализации
- **models/** — обучение и сохранение моделей (SARIMA, Prophet), сравнение моделей
- **run_all_analysis.py** — запуск полного анализа

Вся обработка построена модульно: каждый этап анализа реализован отдельным скриптом, что облегчает расширение и модификацию.

## Демонстрация

- Пример запуска анализа:
  ```bash
  python eda_prophet_sarima/run_all_analysis.py
  ```
- Примеры визуализаций и результатов находятся в папке `eda_prophet_sarima/eda_results/unfiltered/figures/`
- [Презентация](https://github.com/MaximIgitov/cup_it_25/blob/main/Финал.pdf)

## Заключение

Проект позволяет получить комплексное представление о структуре и динамике платежей, выявить ключевые факторы и построить прогнозы на основе реальных данных без фильтрации. Решение может быть расширено для других задач анализа медицинских или финансовых данных.
